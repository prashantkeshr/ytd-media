Troubleshooting

Media engine error

Click System Check. If FFmpeg is red click Repair Engine, then restart.

Format unavailable

Dhurta tries up to 6 fallback strategies. Re-analyze if the source changed.

Browser cookie locked

Keep Use browser session off. Cookie-free is the recommended default.

Download stuck

Downloading = yt-dlp in progress. Processing = FFmpeg merging. Fallback = switching format.

MP4 issues

MP4 prefers H.264+M4A. If unavailable Dhurta falls back to a compatible container.

Exact diagnosis

Open the job's Technical log — the first ERROR line identifies the failing stage.
